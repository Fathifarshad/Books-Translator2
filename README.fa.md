# دوزبانه (Dozabaneh)

مترجم و خوانندهٔ دوزبانهٔ کتاب: PDF انگلیسی ← متن ساختاریافته ← واژه‌نامه ← ترجمه ← ویراستاری دقیق ← خوانندهٔ
چهارستونی (فهرست | ترجمهٔ فارسی | متن انگلیسی | «بپرس از مدرس»). نسخهٔ وب اول ساخته می‌شود و بعدها با Capacitor
به اپ اندروید و iOS تبدیل می‌شود. مشخصات کامل: [`docs/SPEC.md`](docs/SPEC.md) · پیشرفت: [`docs/PROGRESS.md`](docs/PROGRESS.md)
· تصمیم‌ها: [`docs/DECISIONS.md`](docs/DECISIONS.md)

## وضعیت فعلی

- **فاز ۰ (پایه):** مونوریپوی pnpm، TypeScript سخت‌گیرانه، Biome، Vitest، Playwright، سرور Fastify با `/api/v1/health`.
- **فاز ۱ (خواننده و مدرس با کتاب نمونه):** کتابخانه، خوانندهٔ چهارستونی راست‌به‌چپ، واژه‌نامهٔ زیرخط‌دار با کارت
  توضیح، نوار ابزار انتخاب متن («بپرس درباره‌ی این»)، ابزار هر بند (پرسیدن، ویرایش ترجمه با تاریخچه، کپی، یادداشت
  مترجم و هشدار کیفیت)، چکیدهٔ بخش، جستجو (Ctrl/⌘+K)، میان‌برهای صفحه‌کلید، پوسته‌های روشن/کاغذی/تیره، آزمون فصل،
  و ستون مستقل مدرس با پاسخ جریانی، ارجاع به بندها، شبیه‌سازی خطای شبکه و «تلاش دوباره».
- موتور هوش مصنوعی در این مرحله **شبیه‌ساز (mock)** است؛ حالت Claude Code در فاز ۳ و اتصال API در فاز ۴ می‌آید.
- کتاب نمونه («گام‌به‌گام اندیشیدن») متنی **اصیل** است که برای همین پروژه نوشته شده؛ هیچ متن دارای حق نشری در مخزن نیست.

## پیش‌نیازها

- Node.js نسخهٔ ۲۲٫۲۲ یا بالاتر (نسخهٔ LTS فعلی توصیه می‌شود)
- pnpm از طریق corepack: `corepack enable`

## نصب و اجرا

```bash
pnpm install
pnpm dev          # API روی 8787 و وب روی 5173
```

سپس نشانی `http://localhost:5173` را باز کنید و «شروع مطالعه» را بزنید.

## آزمون‌ها

```bash
pnpm lint         # Biome
pnpm typecheck    # TypeScript در همهٔ بسته‌ها
pnpm test         # Vitest (واحد)
pnpm exec playwright install chromium   # فقط بار اول
pnpm e2e          # Playwright (دسکتاپ 1440×900 و موبایل 390×844 + axe)
pnpm screens      # تصویرهای فاز در docs/screens/phase-1/
```

اگر Chromium از پیش نصب است، مسیرش را در `PW_CHROMIUM_PATH` بگذارید تا Playwright از همان استفاده کند.

## ساختار

```
apps/web        اپ React (SPA، آمادهٔ Capacitor)
apps/api        سرور Fastify
packages/text   رجیستری زبان‌ها، دوجهتی‌سازی، ارقام، نشانه‌گذاری، تطبیق واژه‌نامه، نرمال‌سازی جستجو
packages/shared طرح‌واره‌ها و انواع مشترک + کتاب نمونه
packages/core   درخت کتاب، بخش‌ها، شمارندهٔ ترجمه، جستجو، بافت و ارجاع‌های مدرس
packages/ai     لایهٔ موتور (فعلاً شبیه‌ساز: مدرس، چکیده، آزمون)
prompts/        پرامپت‌ها و راهنمای سبک فارسی — مشترک برای همهٔ موتورها
```
