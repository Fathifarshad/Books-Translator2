# دوزبانه (Dozabaneh)

مترجم و خوانندهٔ دوزبانهٔ کتاب: PDF انگلیسی ← متن ساختاریافته ← واژه‌نامه ← ترجمه ← ویراستاری دقیق ← خوانندهٔ
چهارستونی (فهرست | ترجمهٔ فارسی | متن انگلیسی | «بپرس از مدرس»). نسخهٔ وب اول ساخته می‌شود و بعدها با Capacitor
به اپ اندروید و iOS تبدیل می‌شود. مشخصات کامل: [`docs/SPEC.md`](docs/SPEC.md) · پیشرفت: [`docs/PROGRESS.md`](docs/PROGRESS.md)
· تصمیم‌ها: [`docs/DECISIONS.md`](docs/DECISIONS.md)

## وضعیت فعلی

- **فاز ۰ (پایه):** مونوریپوی pnpm، TypeScript سخت‌گیرانه، Biome، Vitest، Playwright، سرور Fastify با `/api/v1/health`.
- **فاز ۱ (خواننده و مدرس با کتاب نمونه):** کتابخانه، خوانندهٔ چهارستونی راست‌به‌چپ، واژه‌نامهٔ زیرخط‌دار با کارت
  توضیح، نوار ابزار انتخاب متن («بپرس درباره‌ی این»)، ابزار هر بند (پرسیدن، ویرایش ترجمه با تاریخچه، کپی، یادداشت
  مترجم و هشدار کیفیت)، چکیدهٔ بخش، جستجو (Ctrl/⌘+K)، میان‌برهای صفحه‌کلید، پوسته‌های روشن/کاغذی/تیره، آزمون فصل،
  و ستون مستقل مدرس با پاسخ جریانی، ارجاع به بندها، شبیه‌سازی خطای شبکه و «تلاش دوباره».
- **فاز ۲ (سرور، پایگاه داده و استخراج PDF):** بارگذاری PDF، استخراج متن و ساختار در پس‌زمینه با نمایش زندهٔ پیشرفت،
  گزارش استخراج (سرصفحه/پاصفحه‌های حذف‌شده، بندهای به‌هم‌پیوسته، واژه‌های خط‌تیره‌دار ترمیم‌شده، بندهای مشکوک)،
  ویرایشگر ساختار (تغییر عنوان، «ترجمه نشود»، بالا/پایین بردن سطح، ادغام، تقسیم)، خواندن متن انگلیسی کتاب در خواننده
  و جستجوی سریع (SQLite FTS5).
- موتور هوش مصنوعی در این مرحله **شبیه‌ساز (mock)** است؛ ترجمه با حالت Claude Code در فاز ۳ و اتصال API در فاز ۴ می‌آید.
- کتاب نمونه («گام‌به‌گام اندیشیدن») متنی **اصیل** است که برای همین پروژه نوشته شده؛ هیچ متن دارای حق نشری در مخزن نیست.

## پیش‌نیازها

- Node.js نسخهٔ ۲۲٫۲۲ یا بالاتر (نسخهٔ LTS فعلی توصیه می‌شود)
- pnpm از طریق corepack: `corepack enable`

## نصب و اجرا

```bash
pnpm install
pnpm dev          # API روی 8787 و وب روی 5173
```

سپس نشانی `http://localhost:5173` را باز کنید و «شروع مطالعه» را بزنید.

## آزمایش با PDF خودتان

1. `pnpm dev` را اجرا کنید و به `http://localhost:5173/books/new` بروید (یا در کتابخانه «افزودن کتاب»).
2. فایل PDF را بکشید و رها کنید یا «انتخاب فایل» را بزنید. پیشرفت استخراج زنده نمایش داده می‌شود.
3. گزارش استخراج و ساختار را بررسی و در صورت نیاز اصلاح کنید، سپس «تأیید ساختار» را بزنید تا متن انگلیسی در خواننده باز شود.

فایل‌ها فقط روی دستگاه خودتان در پوشهٔ `data/` (بیرون از git) ذخیره می‌شوند: پایگاه داده در `data/app.db` و PDFها در
`data/uploads/`. هیچ PDF یا متن کتاب واقعی را commit نکنید؛ برای نگه‌داشتن فایل‌های آزمایشی از `data/private/` استفاده کنید.

برای دیدن جزئیات استخراج بدون اجرای سرور:

```bash
pnpm pdf:inspect data/private/book.pdf                       # بلوک‌ها، ساختار و گزارش در ترمینال
pnpm pdf:inspect data/private/book.pdf --pages 10-20 --html data/private/inspect.html   # نمایش رنگی بلوک‌ها روی صفحه‌ها
```

دستورهای پایگاه داده: `pnpm db:migrate` (اعمال مهاجرت‌ها) و `pnpm db:seed` (افزودن کتاب نمونه). تنظیمات در `.env`
(نمونه: `.env.example`) — از جمله `DATA_DIR`، `MAX_UPLOAD_MB` و `MAX_PAGES`.

## آزمون‌ها

```bash
pnpm lint         # Biome
pnpm typecheck    # TypeScript در همهٔ بسته‌ها
pnpm test         # Vitest (واحد)
pnpm exec playwright install chromium   # فقط بار اول
pnpm e2e          # Playwright (دسکتاپ 1440×900 و موبایل 390×844 + axe)
pnpm screens      # تصویرهای فازها در docs/screens/phase-N/
pnpm fixtures:pdf # ساخت دوبارهٔ PDFهای آزمایشی مصنوعی در fixtures/pdf/
```

آزمون‌های e2e سرور را با پوشهٔ دادهٔ موقت `data/e2e` (پورت 8797) اجرا می‌کنند و به دادهٔ شما دست نمی‌زنند.

اگر Chromium از پیش نصب است، مسیرش را در `PW_CHROMIUM_PATH` بگذارید تا Playwright از همان استفاده کند.

## ساختار

```
apps/web        اپ React (SPA، آمادهٔ Capacitor)
apps/api        سرور Fastify: SQLite + Drizzle، صف کارها، SSE، جستجوی FTS5
packages/text   رجیستری زبان‌ها، دوجهتی‌سازی، ارقام، نشانه‌گذاری، تطبیق واژه‌نامه، نرمال‌سازی جستجو
packages/shared طرح‌واره‌ها و انواع مشترک + کتاب نمونه
packages/core   درخت کتاب، بخش‌ها، ویرایش ساختار، شمارندهٔ ترجمه، جستجو، بافت و ارجاع‌های مدرس
packages/pdf    استخراج PDF با pdf.js در worker: سطرها، حذف سرصفحه/پاصفحه، ستون‌ها، بندها، ساختار، گزارش
fixtures/pdf    PDFهای مصنوعی (متن اصیل) + خروجی طلایی JSON برای آزمون‌ها
packages/ai     لایهٔ موتور (فعلاً شبیه‌ساز: مدرس، چکیده، آزمون)
prompts/        پرامپت‌ها و راهنمای سبک فارسی — مشترک برای همهٔ موتورها
```
