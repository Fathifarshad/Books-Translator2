# راهنمای قدم‌به‌قدم دوزبانه — با روش‌های رایگان

این راهنما نشان می‌دهد برنامه را روی رایانه‌ی خودتان نصب و اجرا کنید، یک PDF بدهید و آن را ترجمه کنید.
همه‌ی ابزارهای لازم رایگان‌اند. درباره‌ی موتور ترجمه:

| روش | هزینه | نحوه‌ی وصل کردن |
|---|---|---|
| OpenRouter (مدل‌های رایگان) | رایگان، حدود ۵۰ درخواست در روز | **یک کلیک** روی «اتصال با یک کلیک» (بخش ۷-الف) |
| Google Gemini (سهمیه‌ی رایگان) | رایگان با سقف روزانه | یک لینک برای گرفتن کلید + چسباندن؛ آزمایش خودکار (بخش ۷-ب) |
| Ollama (مدل محلی روی رایانه‌ی خودتان) | کاملاً رایگان و آفلاین | نصب برنامه و دریافت یک مدل؛ بدون کلید (بخش ۷-ج) |
| موتور «آزمایشی» | رایگان | آماده — فقط برای امتحان مسیر؛ متن فارسی آن ساختگی است |
| Claude Code | رایگان نیست: اشتراک Pro یا Max لازم دارد (بدون هزینه‌ی جداگانه‌ی API) | آماده (بخش ۶) |

برای خواندن روی موبایل (نسخه‌ی آفلاین یا لینک آنلاین) بخش ۸ را ببینید.

---

## ۱. نصب پیش‌نیازها (یک بار)

1. **Node.js** نسخه‌ی ۲۲٫۲۲ یا بالاتر (نسخه‌ی LTS) را از `https://nodejs.org` نصب کنید.
2. **Git** را از `https://git-scm.com` نصب کنید.
3. یک ترمینال باز کنید (در ویندوز: PowerShell) و بنویسید:

```bash
corepack enable
node --version
pnpm --version
```

اگر `corepack enable` در ویندوز خطای دسترسی داد، PowerShell را با «Run as administrator» باز کنید، یا به‌جای آن
`npm install -g pnpm` را بزنید.

## ۲. گرفتن کد برنامه

کد فعلی در شاخه‌ی `claude/pdf-book-translation-app-jz6i99` است (PR شماره‌ی ۱). یکی از این دو راه:

- **پیشنهادی:** PR را در GitHub ادغام (Merge) کنید، سپس:

```bash
git clone https://github.com/Fathifarshad/Books-Translator2.git
cd Books-Translator2
```

- یا بدون ادغام:

```bash
git clone https://github.com/Fathifarshad/Books-Translator2.git
cd Books-Translator2
git checkout claude/pdf-book-translation-app-jz6i99
```

## ۳. نصب و اجرا

```bash
pnpm install
pnpm dev
```

سپس در مرورگر `http://localhost:5173` را باز کنید. کتاب نمونه‌ی «گام‌به‌گام اندیشیدن» در کتابخانه هست.
برای بستن برنامه در ترمینال `Ctrl + C` را بزنید. داده‌ها در پوشه‌ی `data/` می‌مانند و وارد git نمی‌شوند.

## ۴. افزودن کتاب

1. در کتابخانه «افزودن کتاب» را بزنید (یا `http://localhost:5173/books/new`).
2. فایل PDF را بکشید و رها کنید. پیشرفت استخراج زنده نمایش داده می‌شود.
3. «گزارش استخراج» را ببینید: تعداد صفحه‌ها، فصل‌ها و هشدارها (مثلاً صفحه‌های اسکن‌شده یا بندهای مشکوک).
4. در «بازبینی ساختار» عنوان‌ها را بررسی کنید؛ در صورت نیاز تغییر عنوان، «این بخش ترجمه نشود»، بالا/پایین بردن سطح،
   ادغام یا تقسیم. سپس «تأیید ساختار» را بزنید.

## ۵. امتحان رایگان کل مسیر با موتور «آزمایشی»

1. در «تنظیمات ترجمه» برای هر چهار کار (معرفی کتاب، واژه‌نامه، ترجمه، ویراستاری) گزینه‌ی «آزمایشی» را انتخاب کنید.
2. «شروع ترجمه» را بزنید. پس از چند ثانیه مرحله‌ی «معرفی کتاب و واژه‌نامه» باز می‌شود.
3. «تأیید واژه‌نامه و ادامه» را بزنید، سپس «رفتن به داشبورد پردازش».
4. وقتی وضعیت «پایان‌یافته» شد: «صف بازبینی»، «واژه‌نامه» و «خواندن» را ببینید.

متن فارسی این موتور ساختگی است؛ این مرحله فقط برای آشنایی با صفحه‌هاست.

## ۶. ترجمه‌ی واقعی با Claude Code (اگر اشتراک Pro یا Max دارید)

1. Claude Code را نصب کنید (راهنمای رسمی: `https://code.claude.com/docs`)، مثلاً:

```bash
npm install -g @anthropic-ai/claude-code
```

2. در «تنظیمات ترجمه» موتورها را روی «Claude Code» بگذارید (پیش‌فرض) و «شروع ترجمه» را بزنید.
   برنامه پیام «۱ بسته در انتظار Claude Code» و دستور لازم را نشان می‌دهد.
3. یک ترمینال دوم باز کنید، به پوشه‌ی پروژه بروید و Claude Code را اجرا کنید:

```bash
cd Books-Translator2
claude
```

4. در Claude Code بنویسید: `/process-batches 5`
   Claude Code بسته‌ها را یکی‌یکی می‌گیرد، طبق `prompts/` و راهنمای سبک فارسی ترجمه می‌کند و نتیجه را وارد برنامه می‌کند.
5. پس از بسته‌های «واژه‌نامه»، برنامه منتظر شماست: در مرحله‌ی ۵ معادل‌ها را بررسی و «تأیید واژه‌نامه و ادامه» را بزنید.
6. دوباره `/process-batches 10` را بزنید و تا وقتی بسته‌ای باقی است تکرار کنید. بخش‌های آماده همان لحظه در خواننده
   دیده می‌شوند.
7. در پایان «صف بازبینی» را باز کنید و بندهای هشداردار را تأیید یا ویرایش کنید (کلیدهای J و K برای جابه‌جایی).

دستورهای کمکی: `pnpm -s agent:status` (بسته‌های باز)، `pnpm -s agent:release <batchId>` (پس دادن بسته‌ی گیرکرده).

## ۷. ترجمه و مدرس رایگان: OpenRouter، Gemini یا Ollama

همه‌ی کارها در یک صفحه انجام می‌شود: در کتابخانه روی آیکن چرخ‌دنده («تنظیمات») بزنید، یا مستقیم
`http://localhost:5173/settings` را باز کنید، و به بخش **«موتور هوش مصنوعی»** بروید. هر روش یک کارت دارد و وضعیتش
(«وصل است» / «وصل نیست») بالای کارت نوشته می‌شود. یکی کافی است؛ می‌توانید هر سه را هم وصل کنید.

> کلیدها فقط روی سرور همین رایانه و **رمزشده** (در `data/`) نگه داشته می‌شوند، به مرورگر برنمی‌گردند و وارد git
> نمی‌شوند. پوشه‌ی `data/` را با کسی به اشتراک نگذارید.

### الف) OpenRouter — اتصال با یک کلیک (ساده‌ترین)

1. در کارت **OpenRouter** دکمه‌ی **«اتصال با یک کلیک»** را بزنید. صفحه‌ی OpenRouter باز می‌شود.
2. اگر حساب ندارید، «Sign in» و سپس ثبت‌نام با حساب Google را بزنید (رایگان، بدون کارت بانکی).
3. در صفحه‌ی اجازه، دکمه‌ی **«Authorize»** را بزنید.
4. خودکار به همین صفحه برمی‌گردید و پیام سبز **«OpenRouter وصل شد و یک مدل رایگان انتخاب شد.»** را می‌بینید.
   نیازی به کپی کردن هیچ کلیدی نیست.

نکته‌ها:
- برنامه را با نشانی `http://localhost:5173` باز کنید؛ OpenRouter فقط به `localhost` یا نشانی‌های `https` برمی‌گردد.
- مدل‌های رایگان OpenRouter حدود ۵۰ درخواست در روز دارند (ممکن است تغییر کند)؛ برای یک کتاب بلند، Gemini یا
  Ollama مناسب‌ترند. برای عوض کردن مدل: «تنظیمات بیشتر» ← «مدل» (فقط مدل‌های رایگان نشان داده می‌شوند).

### ب) Google Gemini — یک لینک برای گرفتن کلید، سپس چسباندن

1. در کارت **Google Gemini** دکمه‌ی **«گرفتن کلید رایگان از Google AI Studio»** را بزنید. صفحه‌ی
   `https://aistudio.google.com/apikey` در زبانه‌ی تازه باز می‌شود.
2. با حساب Google وارد شوید و **«Create API key»** را بزنید (اگر پروژه خواست، پروژه‌ی پیشنهادی را بپذیرید)، سپس
   **«Copy»** را بزنید.
3. به زبانه‌ی برنامه برگردید، داخل کادر «کلید را اینجا بچسبانید» کلیک کنید و `Ctrl + V` بزنید (یا دکمه‌ی
   «چسباندن از کلیپ‌بورد»). برنامه **خودش** کلید را ذخیره و آزمایش می‌کند و پیام سبز
   **«اتصال برقرار است: مدل … پاسخ داد»** را نشان می‌دهد.

نکته‌ها:
- سقف‌های رایگان Gemini بسته به مدل فرق می‌کنند و Google آن‌ها را گاهی تغییر می‌دهد. برنامه به‌طور پیش‌فرض محتاطانه
  کار می‌کند (۱۰ درخواست در دقیقه و ۴۰۰ در روز) و اگر Google بگوید سهمیه تمام شده، صبر می‌کند و بعداً **خودش** ادامه
  می‌دهد. این اعداد در «تنظیمات بیشتر» قابل تغییرند.
- **حریم خصوصی:** در سهمیه‌ی رایگان، Google ممکن است متن‌های ارسالی را برای بهبود مدل‌هایش به کار ببرد. اگر
  نمی‌خواهید متن کتاب از رایانه‌تان خارج شود، روش «ج» را انتخاب کنید.

### ج) Ollama — مدل محلی، کاملاً رایگان و آفلاین (کندتر)

1. در کارت **Ollama** روی «دانلود Ollama» بزنید (`https://ollama.com/download`)، آن را نصب و اجرا کنید.
2. یک مدل چندزبانه که فارسی را پشتیبانی می‌کند دریافت کنید. نام دقیق و اندازه‌ها را در «کتابخانه‌ی مدل‌های Ollama»
   (`https://ollama.com/library`) ببینید؛ نمونه (در ترمینال):

```bash
ollama pull aya-expanse
```

3. در کارت Ollama دکمه‌ی **«بررسی دوباره»** را بزنید؛ باید «Ollama پیدا شد — N مدل» بیاید. مدل را از فهرست انتخاب
   کنید؛ برنامه خودکار آزمایشش می‌کند.

نکته‌ها: برای مدل‌های حدود ۸ میلیارد پارامتر دست‌کم ۸ تا ۱۶ گیگابایت حافظه لازم است و با کارت گرافیک سریع‌تر است.
برنامه برای Ollama قطعه‌های کوچک‌تری از کتاب می‌فرستد و اندازه‌ی حافظه‌ی متن (context) را خودش تنظیم می‌کند.
کیفیت فارسی مدل‌های محلی از مدل‌های بزرگ آنلاین پایین‌تر است؛ صف بازبینی را جدی بگیرید. اگر Ollama روی رایانه‌ی
دیگری است، نشانی آن را در «تنظیمات بیشتر ← نشانی سرویس» بنویسید.

### د) استفاده از موتور وصل‌شده

- **ترجمه‌ی کتاب:** در «تنظیمات ترجمه»ی هر کتاب، موتور هر کار به‌طور پیش‌فرض اولین موتور رایگانِ وصل‌شده است. با
  «همه‌ی کارها با» می‌توانید یک موتور را برای هر چهار کار انتخاب کنید. موتورهای وصل‌نشده با «(وصل نیست)» غیرفعال‌اند.
- **مدرس، چکیده و آزمونک:** در همان صفحه‌ی «تنظیمات»، بخش «موتور مدرس، چکیده و آزمونک» را روی موتور دلخواه بگذارید.
  نام موتور بالای ستون «بپرس از مدرس» نمایش داده می‌شود.
- **داشبورد پردازش:** بخش «موتورهای هوش مصنوعی» مصرف امروز (مثلاً «امروز ۳۷ از ۴۰۰ درخواست») و زمان درخواست بعدی را
  نشان می‌دهد. اگر کلیدی رد شود، ترجمه متوقف نمی‌شود بلکه منتظر می‌ماند تا در «تنظیمات» درستش کنید.

## ۸. استفاده روی موبایل (مثلاً گوشی اندروید پسرتان)

دو راه دارد؛ هر دو را می‌توانید با هم داشته باشید. بخش «تنظیمات ← دسترسی از موبایل» هم همین مراحل را نشان می‌دهد.

### الف) نسخه‌ی آفلاین — یک فایل، بدون اینترنت و بدون روشن بودن رایانه‌ی شما

1. در کتابخانه روی «⋯» کارت کتاب بزنید و **«نسخه‌ی آفلاین برای موبایل»** را انتخاب کنید. یک فایل `.html` دانلود
   می‌شود (مثلاً `Thinking in Steps.html`).
2. فایل را در تلگرام یا واتس‌اپ برای پسرتان بفرستید.
3. روی گوشی، فایل را باز کند (اگر پرسید، با **Chrome**). فهرست، فارسی / دوزبانه / انگلیسی، جستجو، واژه‌نامه، اندازه‌ی
   قلم و حالت تیره کار می‌کنند و جای مطالعه را به خاطر می‌سپارد.
4. مدرس در این نسخه نیست. هر وقت بخش‌های تازه‌ای ترجمه شد، فایل را دوباره بسازید و بفرستید.

### ب) دسترسی آنلاین از هر جا — کل برنامه با مدرس

1. در «تنظیمات ← دسترسی از موبایل» یک **رمز ورود** بگذارید (دست‌کم ۶ نویسه) و آن را به پسرتان بگویید.
2. یک بار ابزار رایگان Cloudflare را نصب کنید (در PowerShell):

```
winget install --id Cloudflare.cloudflared
```

   سپس PowerShell را ببندید و دوباره باز کنید.
3. هر بار که می‌خواهید پسرتان وصل شود، **به‌جای** `pnpm dev` این را بزنید:

```
cd Books-Translator2
pnpm share
```

   برنامه ساخته و اجرا می‌شود و چند ثانیه بعد یک لینک مثل `https://…trycloudflare.com` نشان داده می‌شود (در «تنظیمات
   ← دسترسی از موبایل» هم هست). روی رایانه‌ی خودتان برنامه را از `http://localhost:8787` باز کنید.
4. لینک را برای پسرتان بفرستید. در Chrome گوشی بازش کند، رمز را وارد کند و از منوی ⋮ گزینه‌ی **«افزودن به صفحه‌ی
   اصلی» (Add to Home screen)** را بزند تا مثل یک برنامه روی گوشی باشد.

نکته‌ها:
- تا وقتی پنجره‌ی `pnpm share` باز و رایانه روشن و بیدار است، لینک کار می‌کند. هر بار که `pnpm share` را دوباره اجرا
  کنید لینک عوض می‌شود؛ لینک تازه را دوباره بفرستید (رمز همان است).
- موبایل فقط **می‌خواند**: کتاب‌ها، دانلود نسخه‌ی آفلاین و مدرس. افزودن یا حذف کتاب، ویرایش ترجمه و تنظیمات فقط روی
  رایانه‌ی شما ممکن است. با تغییر رمز، همه‌ی گوشی‌ها باید دوباره وارد شوند.
- اگر گوشی به همان Wi-Fi خانه وصل است، نشانی «روی همان Wi-Fi» که `pnpm share` چاپ می‌کند هم کار می‌کند (بدون
  Cloudflare؛ ممکن است ویندوز اجازه‌ی دسترسی شبکه بخواهد).

## ۹. رفع اشکال

- **صفحه باز نمی‌شود:** ترمینال `pnpm dev` باید باز بماند؛ پیام خطای آن را ببینید. درگاه‌ها: وب 5173 و API 8787.
- **«سرور در دسترس نیست»:** `pnpm dev` را دوباره اجرا کنید.
- **شروع از صفر:** برنامه را ببندید و پوشه‌ی `data/` را پاک کنید (همه‌ی کتاب‌ها و ترجمه‌ها پاک می‌شوند).
- **بسته‌ای گیر کرده:** `pnpm -s agent:status` و در صورت نیاز `pnpm -s agent:release <batchId>`؛ بسته‌ی امانتی پس از
  ۶۰ دقیقه خودکار آزاد می‌شود.
- **«کلید پذیرفته نشد»:** کلید را دوباره از AI Studio کپی و در کادر بچسبانید (یک کلید تازه هم می‌توانید بسازید).
- **«Ollama پیدا نشد»:** برنامه‌ی Ollama باید باز باشد؛ سپس «بررسی دوباره» را بزنید.
- **«مهلت اتصال تمام شد» (OpenRouter):** دوباره «اتصال با یک کلیک» را بزنید و ظرف ۱۰ دقیقه «Authorize» را بزنید.
- **«سهمیه‌ی رایگان امروز تمام شده است»:** کاری لازم نیست؛ برنامه صبر می‌کند و خودش ادامه می‌دهد. برای سرعت بیشتر
  می‌توانید موتور دوم را هم وصل کنید و بخشی از کارها را به آن بسپارید.
- **کلیدها پس از تغییر `APP_SECRET` خوانده نمی‌شوند:** در «تنظیمات» کلید را دوباره وارد کنید.
- **PDF اسکن‌شده (صفحه‌ها فقط عکس‌اند):** برنامه خودش صفحه‌های اسکن‌شده را با OCR می‌خواند (فعلاً برای کتاب‌های
  انگلیسی). برای هر صفحه چند ثانیه طول می‌کشد؛ کتاب ۳۰۰ صفحه‌ای ممکن است نیم ساعت یا بیشتر طول بکشد. در «گزارش استخراج»
  تعداد «صفحه‌ی خوانده‌شده با OCR» را می‌بینید؛ متن OCR ممکن است خطای خوانش داشته باشد.
- **هرگز** PDF یا متن کتاب را commit نکنید؛ پوشه‌ی `data/` از git بیرون است.
